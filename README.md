# Goat_Studios

Tienda web de ropa full stack con envíos a toda Colombia. Incluye catálogo de productos, carrito de compras, panel de administración con CRUD, autenticación de usuarios y arquitectura por microservicios.

## Funcionalidades

- Home con animación de scroll por frames y secciones de productos (Novedades, Más vendido, Disponible, Precio especial)
- Carrito de compras
- Búsqueda de productos en tiempo real
- Página de detalle de producto con galería, tallas y "Completa el look"
- Stock por talla
- Registro e inicio de sesión (Supabase)
- Perfil de usuario con datos personales, direcciones y métodos de pago
- "Prendas Futuras": cuenta regresiva y votación de productos
- Dashboard de administrador con CRUD de productos, usuarios y carrusel

## Tecnologías

- **Frontend:** React, React Router
- **Backend:** Node.js, Express (microservicios)
- **Base de datos:** PostgreSQL
- **Autenticación:** Supabase
